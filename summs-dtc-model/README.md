# SUMMS DTC Interactive Model

Standalone static site for the unit-economics calculator.

## Deploy (separate Vercel project)

1. [vercel.com/new](https://vercel.com/new) → import `atedays1/brand-segmentation`
2. Set **Root Directory** to `summs-dtc-model`
3. Deploy

You will get a dedicated URL (e.g. `summs-dtc-model.vercel.app`).

## Local

Open `index.html` in a browser, or:

```bash
npx serve .
```
