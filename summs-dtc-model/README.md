# SUMMS DTC Interactive Model

Standalone static site (no Node build). Just `index.html`.

## Deploy on Vercel

1. [vercel.com/new](https://vercel.com/new) → import `atedays1/brand-segmentation`
2. **Root Directory** → `summs-dtc-model`
3. Framework preset: **Other**
4. Install command: leave empty / override to blank
5. Build command: leave empty
6. Output directory: `.` (current folder)
7. Deploy

## Local

Open `index.html` in a browser.
